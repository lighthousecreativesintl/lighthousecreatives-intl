How to Push Updates to Your Published Website

Your student records, receipts, and certificates are stored separately in the cloud so updates won't erase them.

1. Content & Student Updates (Instant)

Any change made inside this Admin panel (programs, fees, facilitators, videos, audio/files, About Us, receipts, uploaded certificates) saves to the cloud and appears immediately on the published site.

2. Code / Layout Updates (Re-publish File)

First click Download Full Site Backup (.json) below. Then export the latest index.html from the chat editor and re-upload/drop it into your hosting host (Netlify / Vercel / cPanel) to publish new code changes.
